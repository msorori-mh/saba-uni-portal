# FACULTY_COUNCILS_WORKSPACE_INFORMATION_ARCHITECTURE_REDESIGN_02

إعادة تنظيم واجهة «مجالسي الأكاديمية» لعضو هيئة التدريس بحيث يصبح **المجلس هو السياق الرئيسي**، ثم **الاجتماع المختار** مساحة عمل مستقلة. Source-only: لا Migration، لا تغيير في RPCs أو الصلاحيات، لا نشر.

## المشكلة الحالية (مؤكدة من المصدر)

- الصفحة الواحدة `faculty-portal.academic-councils.tsx` تعرض: ملخص + إجراءات + مجالسي + الاجتماع القادم + لوحة العمل + طابور المواضيع + تبويبات + قسم «الجلسة الحية والحوكمة».
- قسم الحوكمة يُصيّر `CouncilSessionAndGovernanceWorkspace` **لكل اجتماع** ضمن ست حالات (`agenda_ready` … `archived`) — أي عدة اجتماعات كاملة في صفحة واحدة.
- لوحة القرارات داخل ذلك المكوّن تُحمَّل بـ `council_id` وليس `meeting_id`، لذلك يتكرر القرار نفسه أسفل كل اجتماع.
- «الأرشيف» موجود مرتين: زر أعلى الصفحة + تبويب.
- تقسيم الاجتماعات «قادمة/سابقة» يعتمد على الوقت المجدول فقط، فتظهر الجلسة المنعقدة ضمن «السابقة».
- محرر المحضر يظهر للعضو كـ Textarea معطلة مع نص «اكتب بنود وقرارات…».

## البنية الجديدة

```text
مجالسي الأكاديمية
└── اختيار المجلس (Selector أعلى الصفحة / Sidebar على الشاشات الكبيرة)
    └── لوحة المجلس المختار (4 بطاقات + مؤشر «مطلوب منك الآن»)
        └── تبويبات: نظرة عامة | الاجتماعات | الموضوعات | القرارات | الأرشيف | التقارير
            └── الاجتماعات → فتح اجتماع واحد → مساحة عمل الاجتماع
                └── ملخص | جدول الأعمال | الجلسة والتصويت | المحضر | القرارات
```

## نطاق التنفيذ

1. **سياق المجلس**: Council Selector أعلى الصفحة (Dropdown على الجوال، قائمة جانبية على الشاشات الكبيرة) يعرض اسم المجلس + الدور + حالة العضوية. كل ما تحته مفلتر على `council_id` المختار فقط (الاجتماعات، الموضوعات، القرارات، الأرشيف).
2. **لوحة المجلس**: أربع بطاقات: حالة المجلس الآن (جلسة جارية / لا يوجد)، الاجتماع التالي، موضوعاتي، مطلوب مني. تُستبدل ازدواجية «يحتاج إجراء مني» + `CouncilsActionRequired` بمؤشر واحد.
3. **أولوية الحالة**: جلسة جارية الآن ← اجتماع يحتاج إجراء ← الاجتماع القادم ← لا يوجد.
4. **تبويبات المجلس**: نظرة عامة، الاجتماعات، الموضوعات، القرارات، الأرشيف، التقارير — ولا يُعرض محتوى تبويب غير نشط.
5. **تصنيف الاجتماعات** حسب الحالة التشغيلية لا الوقت: جاري الآن (`in_session`) / قادم وقيد الإعداد (`scheduled`, `intake_open`, `intake_closed`, `agenda_ready`) / مكتمل (`minutes_draft`, `minutes_review`, `minutes_locked`) / مؤرشف (`archived`).
6. **مساحة عمل الاجتماع**: فتح اجتماع واحد فقط (Drawer/لوحة مخصصة) مع شريط دورة الحياة وتبويبات داخلية. لا يُصيَّر `CouncilSessionAndGovernanceWorkspace` إلا للاجتماع المفتوح.
7. **القرارات على مستوى المجلس**: نقل سجل القرارات والمتابعة إلى تبويب «القرارات» مع إظهار الاجتماع المُصدِر لكل قرار، وقسم فرعي «قرارات مكلف بتنفيذها». إزالة تكراره أسفل كل اجتماع.
8. **المحضر للعضو**: بدل Textarea معطلة، عرض حالة نصية: «المحضر قيد الإعداد بواسطة أمين سر المجلس» أو «المحضر معتمد ومقفل رسميًا» + زر تنزيل PDF عند القفل. المحرر يظهر للرئيس/أمين السر فقط (نفس الصلاحية الحالية بلا تغيير).
9. **الموضوعات**: تبويب مستقل (موضوعاتي / موضوعات المجلس) + زر «تقديم موضوع لهذا الاجتماع» يظهر فقط عند وجود اجتماع باستقبال مفتوح **في المجلس المختار**، مع نص واضح عند الإغلاق بدل Dialog فارغ.
10. **إزالة التكرارات**: أرشيف واحد فقط (تبويب)، وإزالة زر «فحص الصلاحيات» من واجهة عضو هيئة التدريس واستبداله ببطاقة «صلاحياتي في المجلس» (يمكنك / لا يمكنك) داخل تبويب نظرة عامة. مسار `authorization-audit` يبقى موجودًا بلا رابط ظاهر للعضو.
11. **مجلس القسم ومجلس الكلية**: نفس الواجهة تمامًا؛ الفرق في نوع المجلس والدور فقط، والأزرار تتبدل حسب الدور المعتمد.

- **ملفات جديدة**: `CouncilContextSelector.tsx`، `CouncilOverviewTab.tsx`، `CouncilMeetingWorkspace.tsx`، `CouncilDecisionsTab.tsx`، `CouncilMyPermissionsCard.tsx`.
