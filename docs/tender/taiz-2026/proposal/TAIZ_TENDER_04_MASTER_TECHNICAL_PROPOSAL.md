## خطاب تقديم العطاء الفني (مسودة رسمية)

**إلى السيد / رئيس لجنة المناقصات والمزايدات بجامعة تعز المحترم،،،**
**تحية طيبة وبعد،،،**

بناءً على كراسة الشروط والمواصفات الفنية والمالية للمناقصة العامة رقم (2) لعام 2026م الخاصة بمشروع *"تصميم وتطوير الموقع الإلكتروني الرسمي لجامعة تعز والبوابة الرقمية المتكاملة ودمج تقنيات الذكاء الاصطناعي"*، وبعد دراستنا المتعمقة والدقيقة لكافة متطلبات الكراسة والبنود والشروط التشريعية والتنفيذية؛

يسرنا أن نتقدم إليكم بعرضنا الفني المتكامل، والذي يمثل **حلًا سيادياً موحداً عالي الأداء وقابلاً للتوسع** يرتكز على المعايير الهندسية المؤسسية بنمط المعمارية الموحدة (*Modular Monolith*)، ويوفر:
1. **موقعاً مؤسسياً مركزياً ومنصة إدارة محتوى متعددة المواقع (*Multi-Site CMS*)** تدير 25 موقعاً فرعياً للكليات والمراكز عبر نطاقات فرعية مستقلة (`*.taiz.edu.ye`) بحوكمة مركزية واستقلالية تحريرية.
2. **بوابات رقمية موحدة** للطلاب وأعضاء هيئة التدريس والموظفين مع نظام دخول موحد ومصادقة متعددة العوامل (*SSO / MFA / RBAC*).
3. **محرك ذكاء اصطناعي وبحث دلالي سيادي محلي الاستضافة 100% On-Premises (*Local Sovereign RAG*)** يعتمد على المعالجة الصرفية العربية وقواعد البيانات المتجهية لضمان الخصوصية التامة والاستشهاد الحصري باللوائح المعتمدة.
4. **بوابة تكامل مؤسسية (*API Gateway*)** وموصلات آمنة مع الأنظمة الجامعية القائمة (*SIS / HR / Finance*) دون أي تعطيل أو استبدال غير ضروري.
5. **التزاماً مطلقاً بنقل الملكية الفكرية وتسليم كامل الشفرة المصدرية غير المغلقة (*Full Source Code Git*)** لجامعة تعز، مع ضمان وصيانة مجانية لمدة 12 شهراً وفق اتفاقية مستوى الخدمة (*SLA*).

نؤكد التزامنا التام بكافة نصوص قانون المناقصات والمزايدات اليمني رقم (23) لسنة 2007م ولائحته التنفيذية، واستعدادنا للبدء الفوري في التنفيذ وفق الجدول الزمني المعتمد (32 أسبوعاً).
