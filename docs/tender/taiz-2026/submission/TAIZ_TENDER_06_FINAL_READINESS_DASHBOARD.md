## 4. قرار الحوكمة الصارم (Fail-Closed Rule)

```
[FAIL-CLOSED SUBMISSION GOVERNANCE]
- حزمة العرض الفني جاهزة للطباعة والتصدير الفوري (PACKAGE_READY_FOR_PRINT=TRUE).
- لا يتم تصنيف حزمة التقديم بـ "READY_TO_SUBMIT" حتى يتم اعتماد السعر النهائي،
  وإصدار أصل الضمان البنكي 2% وإرفاقه، وإيداع شهادات الإنجاز وسير الخبراء الموقعة.
```
