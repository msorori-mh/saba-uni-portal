## 4. بنود الاستبعاد الفوري وبطلان العطاء (Dealbreakers / Disqualification Risks)

1. **الضمان البنكي الابتدائي:** عدم إرفاق أصل الضمان بنسبة 2%، أو صدوره بصيغة مشروطة، أو سريانه لأقل من 90 يوماً.
2. **البطاقات القانونية:** انتهاء أو غياب أي من (البطاقة الضريبية، الزكوية، التأمينية، ضريبة المبيعات، السجل التجاري لعام 2026م).
3. **خلط المظاريف:** وضع أي أسعار أو مبالغ مالية داخل المظروف الفني، أو عدم إغلاق المظاريف وتختيمها بالشمع الأحمر.
4. **الملكية الفكرية:** أي تحفظ أو رفض لنقل الملكية الفكرية وتسليم كامل الشفرة المصدرية (Full Source Code Git) للجامعة.
5. **الدرجة الفنية دون 75:** الحصول على أقل من 75 درجة في التقييم الفني يمنع فتح المظروف المالي ويستبعد العطاء نهائياً.
