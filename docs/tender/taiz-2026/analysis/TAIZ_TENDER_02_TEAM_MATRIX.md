## 2. تفصيل المتطلبات والأدلة لكل دور

### 2.1 مدير المشروع (Project Manager)
- **المسؤوليات الرئيسية:** إدارة النطاق، الجدول الزمني، المخاطر، الجودة، والتنسيق الكامل مع لجنة الجامعة الفنية وإعداد التقارير الشهرية.
- **الأدلة الإلزامية:** سيرة ذاتية مفصلة + صورة طبق الأصل لشهادة PMP/PRINCE2 سارية + شهادات خبرة 8 سنوات في مشاريع حكومية/جامعية + خطاب التزام بالتفرغ 100%.
- **خطر عدم التوفر:** فقدان درجات معيار فريق العمل وتعريض إدارة المشروع للارتباك.

### 2.2 قائد معمارية الحلول (Solutions Architect)
- **المسؤوليات الرئيسية:** تصميم معمارية Modular Monolith، تخطيط الـ API Gateway، وتحديد حدود المكونات وقابلية التوسع لـ 25,000 مستخدم.
- **الأدلة الإلزامية:** سيرة ذاتية + صورة شهادة TOGAF أو AWS Certified Solutions Architect سارية + نماذج وثائق معمارية لمشاريع كبرى سابقة.
- **خطر عدم التوفر:** تشكيك اللجنة في متانة المعمارية ورفض المخرج المعماري D-05.

### 2.3 قائد الخدمات الخلفية (Backend Lead)
- **المسؤوليات الرئيسية:** تطوير خدمات البوابات، وتكامل Keycloak SSO، وتصميم قواعد البيانات PostgreSQL، وموصلات الأنظمة القائمة SIS.
- **الأدلة الإلزامية:** سيرة ذاتية + مؤهل جامعي معتمد + خبرة 7 سنوات مثبتة في NestJS/Node.js و PostgreSQL و OIDC.

### 2.4 قائد الواجهات والنفاذية (Frontend Lead)
- **المسؤوليات الرئيسية:** بناء واجهات Next.js المتجاوبة، وتطبيق الـ Design System، وضمان التوافق مع WCAG 2.2 AA وأتمتة الـ SEO.
- **الأدلة الإلزامية:** سيرة ذاتية + مؤهل جامعي معتمد + خبرة 6 سنوات مثبتة في React/Next.js ودعم RTL/LTR وتطبيقات النفاذية.

### 2.5 مهندس الذكاء الاصطناعي (AI/RAG Specialist)
- **المسؤوليات الرئيسية:** بناء خطوط أنابيب الـ RAG، وإعداد قاعدة بيانات Qdrant، ونماذج التضمين والمعالجة الصرفية العربية، وحوكمة الـ AI.
- **الأدلة الإلزامية:** سيرة ذاتية + مؤهل ماجستير/بكالوريوس في الذكاء الاصطناعي + خبرة 5 سنوات في تطبيقات LLM مفتوحة المصدر (On-Premises).

### 2.6 خبير الأمن السيبراني (Cybersecurity Specialist)
- **المسؤوليات الرئيسية:** تطبيق ضوابط OWASP ASVS Level 2، وإدارة التشفير TLS 1.3/AES-256، والإشراف على فحص الاختراق الخارجي.
- **الأدلة الإلزامية:** سيرة ذاتية + صورة شهادة CISSP أو CEH أو ISO 27001 سارية + سجل تنفيذ اختبارات أمنية معتمدة.

### 2.7 مهندس عمليات DevOps (DevOps Specialist)
- **المسؤوليات الرئيسية:** إعداد خطوط CI/CD، وإدارة كلاستر Kubernetes محلياً، والتوسع التلقائي HPA، وخطة التعافي من الكوارث DR.
- **الأدلة الإلزامية:** سيرة ذاتية + صورة شهادة CKA أو Docker Certified سارية + خبرة 5 سنوات في بيئات الإنتاج المعقدة.

### 2.8 أخصائي ترحيل المحتوى والتدريب (Content/Training Lead)
- **المسؤوليات الرئيسية:** تنفيذ عمليات سحب وهجرة المحتوى التاريخي وأنابيب ETL، وإعداد الأدلة باللغة العربية، وتنفيذ 80 ساعة تدريبية لـ 40 متدرباً.
- **الأدلة الإلزامية:** سيرة ذاتية + مؤهل جامعي في نظم المعلومات + خبرة 4 سنوات في إدارة المحتوى والتدريب وتأليف الأدلة.
