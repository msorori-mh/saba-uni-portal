# قوالب طلب وتوثيق شهادات الإنجاز وسابقة الأعمال
## TAIZ-TENDER-05A — REFERENCE CERTIFICATE TEMPLATES (TRACK A)

> **تصنيف الوثيقة:** `TEMPLATE_NOT_EVIDENCE` (نماذج وقوالب عمل جاهزة للاستخدام وليست دليلاً متوفراً حتى توقيعها وختمها رسمياً).

---

## 1. نموذج طلب شهادة إنجاز واستلام نهائي (خطاب موجه للعميل)

```
التاريخ: .... / .... / 2026م
الرقم الإشاري: ....................

الأخ الأستاذ الدكتور / ................................................................. المحترم
رئيس / عميد / مدير عام ................................................................. المحترم

الموضوع: طلب إصدار شهادة إنجاز واستلام نهائي لمشروع [اسم المشروع المنفذ]

تحية طيبة وبعد،،،

بالإشارة إلى العقد المبرم بيننا وبين جهتكم الموقرة بتاريخ ..../..../........م بشأن تنفيذ وتطوير [اسم المشروع / المنظومة الرقمية]، والذي تم إنجازه وتشغيله بنجاح واستلامه نهائياً وفق المواصفات المعتمدة؛

ونظراً لتقدم شركتنا في مناقصات ومشاريع أكاديمية جديدة، يرجى التكرم بالموافقة على إصدار "شهادة إنجاز واستلام نهائي" وفق النموذج المرفق، متضمنةً تقييمكم لمستوى الأداء الفني والالتزام بالجدول الزمني.

شاكرين ومقدرين حسن تعاونكم الدائم،،،

مقدم الطلب: [اسم الشركة / المفوض الرسمي]
التوقيع: ....................................... الختم: .......................................
```

## 2. نموذج صيغة شهادة الإنجاز والاستلام النهائي المعتمدة

```
================================================================================
الجمهورية اليمنية — [اسم الجهة / الجامعة المصدرة للشهادة]
إدارة تقنية المعلومات / الشؤون الفنية
================================================================================

شهادة إنجاز واستلام نهائي لمشروع برمجيات وتقنية معلومات

تشهد [اسم الجامعة / المؤسسة] بأن الأخوة / شركة ......................................... قد قاموا بتنفيذ وإنجاز مشروع:
[اسم المنظومة / البوابة الإلكترونية / المشروع]

وذلك بموجب العقد رقم (..........) المؤرخ في ..../..../........م، والمبين تفاصيله كالتالي:
1. نطاق العمل المنفذ: [تصميم وتطوير الموقع، البوابات، التكامل مع الأنظمة، التدريب، الضمان].
2. فترة التنفيذ الفعلية: من ..../..../........م إلى ..../..../........م.
3. التقييم الفني للأداء: [ممتاز / تم الإنجاز وفق أعلى المعايير الهندسية].
4. حالة الاستلام: تم الاستلام النهائي للنظام والشفرة المصدرية وتشغيله بالإنتاج بنجاح دون أي ملاحظات أو التزامات معلقة.

وقد أُعطيت لهم هذه الشهادة بناءً على طلبهم لتقديمها للجهات المعنية دون أي مسؤولية على الجهة المصدرة.

المسؤول المختص: ........................................ الصفة: ........................................
التوقيع: ................................................ الختم الرسمي: ...................................
```

## 3. قائمة التحقق من صحة واكتمال الشهادة (Verification Checklist)

- [ ] اسم المشروع والجهة المستفيدة واضح ومطابق لمجال المناقصة.
- [ ] توضيح نطاق العمل التقني (بوابات، CMS، تكامل، أنظمة تعليمية).
- [ ] وجود عبارة صريحة تفيد بالإنجاز التام والاستلام النهائي والتشغيل بنجاح.
- [ ] توقيع المسؤول المخول وختم الجهة المستفيدة الأصلي والواضح.
- [ ] تضمين رقم هاتف وبريد إلكتروني رسمي للجهة لتسهيل التحقق من قبل لجنة التحكيم.
