## 2. اشتراطات التحقق من الشهادات المهنية (Credentials Verification)

1. **شهادة PMP:** التحقق المباشر عبر بوابة PMI Certification Registry باستخدام الرقم المهني والاسم.
2. **شهادة TOGAF:** التحقق عبر دليل The Open Group Directory of Certified People.
3. **شهادة CISSP:** التحقق عبر بوابة (ISC)² Credential Verification.
4. **شهادة CKA:** التحقق عبر منصة The Linux Foundation / Credly Verification Badge.
