# GRADUATION-PROJECTS — USER GUIDES (ALL ROLES)

Common rule for every role: الصلاحية = التعيين المباشر النشط على المشروع فقط.
إخفاء الأزرار ليس حماية؛ كل عملية تُتحقق في الخلفية وترفض برسالة عربية واضحة.

## 1. دليل الطالب

- الدخول: بوابة الطالب → «مشروع التخرج». تُعرض مشاريعك فقط.
- المقترح: في حالة «مسودة» اضغط «تقديم المقترح»؛ إن أُعيد («يتطلب تعديلاً»)
  عدّل ثم «إعادة تقديم».
- الفريق: يُدار من منسق/رئيس القسم (إضافة/إنهاء الأعضاء) — لا إضافة ذاتية.
- المراحل والتسليمات: في «نشط» سلّم مخرجات كل مرحلة، وسجّل الملفات بنوعها
  (pdf/zip/صور/office، حد 50 ميغابايت). بعد مراجعة المشرف: قبول أو «طلب
  تعديل» مع ملاحظة — أعد التسليم كنسخة جديدة.
- المناقشة: عند اكتمال الجاهزية (كل المراحل مقبولة + ملف نهائي سليم الفحص)
  اطلب المناقشة من تبويب المناقشة.
- التقييم: لا ترى أي درجات قبل اعتماد النتيجة.
- التصحيحات: إن طُلبت، نفّذها ثم «إتمام التصحيح» لكل بند.
- الأرشفة: بعد «مكتمل» تتم الأرشفة من رئيس القسم/العميد؛ بعدها المشروع للقراءة فقط.

## 2. دليل المشرف (والمشرف المشارك)

- الدخول: بوابة الأكاديمي → «مشاريع التخرج» (المشاريع المسندة إليك فقط).
- خطة المراحل: حدّد المراحل وأوزانها (المجموع = 100، ترتيب فريد) في «معتمد/نشط».
- المراجعة: قبول أو «طلب تعديل» لكل تسليم (الملاحظة إلزامية عند طلب التعديل)،
  مع ملاحظات إشراف حرة ومعالجتها لاحقاً.
- الجاهزية: بطاقة الجاهزية تبيّن النواقص قبل طلب المناقشة.
- المشرف المشارك: قراءة كاملة فقط — لا مراجعة ولا ملاحظات ولا إجراءات كتابة.
- التصحيحات: تابع حالتها من تبويب النتيجة؛ القبول النهائي لرئيس القسم/العميد.

## 3. دليل رئيس القسم

- الدخول: لوحة الإدارة → «مشاريع التخرج» (مشاريع قسمك فقط).
- المقترحات: بدء المراجعة، اعتماد، رفض، أو طلب تعديل — مع سبب إلزامي للقرارين الأخيرين.
- التعيينات: عيّن المشرف (واحد) والمشارك (واحد كحد أقصى وفق الإعدادات) وأعضاء
  اللجنة؛ أنهِ التعيينات عند الحاجة (لا يمكن إنهاء تعيينك الخاص).
- المناقشات: جدولة (موعد + مكان) أو رفض الطلب؛ تشكيل اللجنة (عضو + رئيس واحد)؛
  تسجيل النتيجة (انعقدت/أجلت/ألغيت) — الانعقاد يتطلب لجنة مكتملة.
- النتيجة والأرشفة: اعتماد النتيجة بعد اكتمال كل التقييمات؛ طلب تصحيحات؛
  قبولها؛ الأرشفة بالملف النهائي سليم الفحص.
- الإعدادات والتقارير: حدد حجم الفريق وطاقة الإشراف والنوافذ؛ راجع تقارير
  الحالات/التعيينات/التقييمات/الأرشيف/المناقشات وصدّر CSV.

## 4. دليل عضو اللجنة

- ترى فقط المشاريع المكلَّف بمناقشتها، والنسخة المسموح بها.
- بعد انعقاد المناقشة: أدخل تقييمك الشخصي (معايير + درجات ≤ العظمى + ملاحظات)،
  احفظ مسودة أو أرسل، ثم «اعتماد تقييمي نهائياً».
- لا ترى مسودات الأعضاء الآخرين؛ لا يمكنك تعديل تقييمك بعد الإرسال/الاعتماد؛
  لا يمكنك إدخال تقييم عضو آخر أبداً.

## 5. دليل الإدارة الأكاديمية (العميد)

- نفس مساحة «مشاريع التخرج» في لوحة الإدارة.
- الصلاحيات: قراءة التقارير، اعتماد النتائج، قبول التصحيحات، الأرشفة، إدارة
  الإعدادات وسلالم التقييم — ضمن العقد فقط.
- لا يوجد تجاوز عام: العميد لا ينفذ مراحل الطالب أو المشرف أو اللجنة نيابة عنهم.

## 6. دليل التقارير الإدارية

- الحالات: توزيع المشاريع بالحالة + المتعثرة + الجاهزة.
- التعيينات: أعباء الإشراف + الفرق + مشاريع بلا مشرف.
- التقييمات: المعتمدة والمتوسطات والتصحيحات المعلقة.
- الأرشيف: المشاريع المؤرشفة وملفاتها النهائية.
- المناقشات: المجدولة (اكتمال اللجنة) + التقييمات الناقصة + توزيع النتائج.
- كل تقرير قابل للتصدير CSV من داخل التبويب.
