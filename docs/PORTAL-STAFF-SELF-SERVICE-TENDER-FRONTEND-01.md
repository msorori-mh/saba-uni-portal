# PORTAL_STAFF_SELF_SERVICE_TENDER_FRONTEND_01

## القرار

مرحلة واجهات أمامية معزولة لدليل مناقصة جامعة تعز. لا تتضمن هذه الحزمة أي ترحيل قاعدة بيانات أو RLS أو RPC أو تخزين أو تكامل خارجي أو كتابة إنتاجية.

## المصدر والنطاق

- المشروع: بوابة كلية تكنولوجيا المعلومات وعلوم الحاسوب.
- الواجهة: بوابة الموظفين ولوحة الإدارة القائمة.
- البيانات: `TEST_ONLY_TENDER_STAFF_SELF_SERVICE_01` فقط.
- الهدف: إثبات التغطية البصرية والمنطقية للخدمات، مع عقد بيانات قابل للاستبدال في المرحلة الثانية.

## واجهات الموظف

1. اللوحة الرئيسية.
2. الملف الوظيفي.
3. الإجازات والمغادرات: الرصيد، الطلب، المرفقات، السجل والقرار.
4. كشف الراتب وPDF والتدرج الوظيفي.
5. المراسلات والتعاميم وتأكيد الاستلام.
6. العُهد والنقل والإرجاع ومحضر التسليم.
7. الطلبات والإشعارات والسجل الزمني.
8. مهام اعتماد المسؤول المباشر.
9. الإفادات وشهادات الخبرة.
10. الأداء، الحضور، العمل الإضافي، التدريب، الترقيات وإخلاء الطرف.

## انعكاس الإدارة

- لوحة مؤشرات خدمات الموظفين.
- صناديق اعتماد Direct Manager وHR.
- دورة نشر كشوف الرواتب المقيدة بدور Finance.
- نشر التعاميم وقياس القراءة والاستلام.
- سجل العُهد ومحاضر النقل والإرجاع.
- الأداء والحضور والتدريب والترقيات وإخلاء الطرف.
- تقارير الموارد البشرية وسجل التدقيق.

## ضوابط العرض

- بيانات وأسماء وأرقام خيالية.
- شريط تنبيه واضح أن المرحلة واجهات للمناقصة.
- الراتب نموذج غير صالح للصرف.
- لا توجد أي دالة Supabase mutation في مكونات العرض أو بياناتها.
- أزرار الاعتماد والنشر والرفع توضح الواجهة فقط ولا تنفذ كتابة.
- حزمة طباعة مستقلة للموظف وحزمة مستقلة للإدارة.

## المرحلة الثانية المؤجلة

نماذج البيانات، RBAC/RLS، مسارات الاعتماد، أرصدة الإجازات، التخزين الخاص، MFA، التكامل الآمن مع HR والمالية والعُهد، الإشعارات، PDF الرسمي والتوقيع والتحقق عبر QR، واختبارات E2E التشغيلية.
