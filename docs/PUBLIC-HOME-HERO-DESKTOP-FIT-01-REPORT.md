## المشكلة قبل الإصلاح

على quboolye.com (والبناء الحالي من `origin/main`) لم يظهر الهيدر + الهيرو كاملين داخل نافذة المتصفح الافتراضية على الشاشات المكتبية الشائعة (خصوصًا 1366×768):

1. الهيرو بارتفاع `min-h-[calc(100vh-14rem)]` مع `py-16 md:py-24`.
2. شعار كبير `h-36 w-36 md:h-40 md:w-40`.
3. عنوان `text-4xl md:text-6xl` يلتف ويزيد الارتفاع.
4. شريط تنقل ثانوي `lg…2xl` يضيف صفًا إضافيًا للهيدر على اللابتوب.
5. صندوق الوصف وزر تسجيل الدخول يسقطان تحت الجزء المرئي.

---

## السبب الجذري

مجموع ارتفاع الهيدر (صف رئيسي + صف تنقل ثانوي على 1024–1535) + هيرو شبه كامل الشاشة مع padding رأسي كبير وشعار/خطوط ضخمة يتجاوز `svh` على ارتفاعات 768–900px.

## القيم السابقة → الجديدة

### الهيرو (`index.tsx`)

| البند | قبل | بعد |
|-------|-----|-----|
| العرض | `max-w-2xl` | `max-w-6xl` |
| الارتفاع | `min-h-[calc(100vh-14rem)]` | `min-h-[clamp(34rem,calc(100svh-10rem),42rem)]` |
| padding رأسي | `py-16 md:py-24` | `py-8 md:py-10 lg:py-12` |
| الشعار | `h-36 w-36 md:h-40 md:w-40` + `p-3` | `h-24…lg:h-32` + `p-2/2.5` |
| العنوان | `text-4xl md:text-6xl` سطران حران | سطران block + `clamp` + `sm:whitespace-nowrap` |
| الصندوق | `mt-6 py-4 max-w-xl leading-7` | `mt-4 py-3 max-w-2xl text-sm leading-6` |
| الزر | `mt-8 px-12 py-4` | `mt-5 px-10 py-3 text-sm sm:text-base` |

### الهيدر (`Header.tsx`)

| البند | قبل | بعد |
|-------|-----|-----|
| الشريط العلوي | `py-1` | `py-0.5` |
| الصف الرئيسي | `py-3 gap-4` | `py-2 gap-3` |
| الشعار | `h-14…lg:h-16` | `h-12…lg:h-14` |
| اسم الكلية | `text-base lg:text-lg` | `text-sm lg:text-base` |
| تنقل رئيسي | `hidden 2xl:flex` | `hidden xl:flex` |
| تنقل ثانوي | `lg…2xl:hidden` | `lg…xl:hidden` |
| أزرار الدخول | `hidden lg:flex` | `hidden 2xl:flex` |

## نتائج المقاسات (تحليل CSS + مراجعة بصرية محلية)

| المقاس | النتيجة المتوقعة بعد الإصلاح |
|--------|------------------------------|
| **1366×768** | هيدر صف واحد (xl) بدون صف ثانوي وبدون أزرار دخول؛ الهيرو ≤ `100svh-10rem` مع حد أدنى 34rem — الشعار + سطران + وصف + زر داخل الشاشة بدون تمرير |
| **1440×900** | هيرو كامل داخل الشاشة؛ قد يظهر جزء من بطاقات البوابات؛ لا التفاف لاسم الكلية من `sm` |
| **1536×864** | مثل 1440؛ عند ≥1536 تظهر أزرار الدخول في الهيدر (`2xl`) |
| **1920×1080** | ارتفاع الهيرو محدود بـ `42rem`؛ محتوى متمركز `max-w-6xl` |
| **768×1024** | clamp يقلّص الخط؛ بدون overflow أفقي؛ صف تنقل ثانوي تحت `xl` |
| **390×844** | قائمة متنقلة؛ السطر الثاني قد يلتف؛ زر الدخول ظاهر |

لا JS لقياس الارتفاع — اعتماد CSS/`svh` فقط.
