## الملخص التنفيذي

تم تأسيس بوابة جديدة معزولة باسم **بوابة إدارة المجالس الأكاديمية** ضمن مجموعة **الشؤون الأكاديمية** في لوحة الإدارة، كصفحة عرض مبدئي فقط دون أي بيانات حقيقية أو تشغيل فعلي.

## الملفات المعدلة/المنشأة

- **جديد:** `src/routes/admin/academic-councils.tsx` — صفحة العرض المبدئي.
- **معدل:** `src/lib/admin-nav.ts` — إضافة `"/admin/academic-councils": ["system_admin", "admin", "dean"]` إلى `NAV_ITEM_ROLES`.
- **معدل:** `src/components/admin/AdminShell.tsx` — إضافة عنصر تنقل واحد إلى مجموعة `academic` بعنوان "بوابة إدارة المجالس الأكاديمية".

لا تعديل على: routes الطلاب، routes الطلبات، التقارير، الخطط الدراسية، الجداول، الإسناد، Faculty portal، migrations، RLS، Storage، Triggers، Edge Functions.

## هيكلة "الشؤون الأكاديمية" بعد الإضافة

مجموعة **الشؤون الأكاديمية** الآن تحتوي المسارات الأكاديمية التشغيلية القائمة (العمليات، البنية، الخطط، الإسناد، التسجيل، الدرجات، السجلات، الاستيراد، التقدم، المتعثرون، مرشحو التخرج) إضافةً إلى مدخل جديد **بوابة إدارة المجالس الأكاديمية**. هذا يحقق المسارين المطلوبين ضمن نفس القسم:
1. المسار الأكاديمي الحالي (كما هو، دون تغيير).
2. بوابة إدارة المجالس الأكاديمية (المدخل الجديد).

## محتوى الصفحة المبدئية

- عنوان + الوصف الرسمي المطلوب حرفياً.
- ملاحظة داخلية بارزة: "هذه البوابة قيد التأسيس ولا تستخدم حالياً بيانات حقيقية."
- 9 بطاقات عرض تصميمي فقط لكل الأقسام المستقبلية: مجلس الكلية، مجالس الأقسام، الاجتماعات القادمة، رفع موضوع جديد، جدول الأعمال، المحاضر والقرارات، متابعة تنفيذ القرارات، الأرشيف، إعدادات الجدولة والتنبيهات — كل بطاقة تحمل شارة "قريباً" وحالة `aria-disabled`.
- لا نماذج، لا استعلامات DB، لا استدعاءات server functions، لا رفع ملفات.

## حماية المسار

- يجلس تحت `/admin/*` وبالتالي يخضع لطبقات الحماية القائمة في `src/routes/admin.tsx` (`getAdminSession` → `canAccessAdminPanel` → `canAccessAdminRoute`).
- الأدوار المسموح لها فقط: `system_admin`, `admin`, `dean`.
- الطلاب والعامة والموظفون غير المخولين: مرفوضون تلقائياً عبر `canAccessAdminRoute` مع إعادة توجيه لأقرب صفحة مسموح بها + بانر تنبيه.
- Meta: `noindex, nofollow`.
- لا يظهر عنصر التنقل إلا للأدوار المخولة بفضل `filterNavGroups`.
