## 5. Security Notes

- **RBAC:** `assertStudentRead` — نفس صلاحية قراءة قائمة الطلاب (`STUDENT_READ_ROLES`).
- **لا service role في المتصفح:** التصدير عبر `createServerFn` + `supabaseAdmin` على الخادم فقط.
- **حماية التصدير غير المفلتر:** يُرفض التصدير بدون فلتر أو رقم أكاديمي (مطابق لسلوك القائمة).
- **حد أقصى:** 5000 صف لمنع تصدير ضخم غير مقصود.
- **تدقيق:** إدراج `audit_logs` بـ `students_exported` (قراءة طلاب + سجل تدقيق تشغيلي — لا تعديل بيانات طلاب).
