## 3. مضمون الهيكل الواجهي

الصفحة الآن تعرض الأقسام التالية بترتيب منطقي، **كلها واجهة فقط بدون أي اتصال بقاعدة بيانات**:

1. **رأس البوابة** — العنوان + الوصف + شارة "قيد التأسيس".
2. **تنبيه العرض** — إشعار بارز أعلى الصفحة بالنص المطلوب حرفياً:
   > «هذه البوابة في مرحلة التأسيس، والبيانات المعروضة لأغراض العرض والتصميم فقط، ولا تمثل بيانات رسمية.»
3. **لوحة المجالس (KPIs)** — 4 مؤشرات كلها بقيمة "قيد التأسيس":
   - الاجتماعات القادمة
   - الموضوعات المرفوعة
   - القرارات قيد المتابعة
   - القرارات المتأخرة
4. **مجلس الكلية** — قائمة توضيحية بمدخل واحد بحالة "قيد التأسيس".
5. **مجالس الأقسام** — قائمة توضيحية بمجالس أقسام (تقنية المعلومات، علوم الحاسوب) — عناوين ثابتة، لا بيانات فعلية.
6. **الاجتماعات القادمة** — قائمة empty-state + زر معطَّل `إنشاء اجتماع`.
7. **رفع موضوع جديد** — empty-state + زر معطَّل `رفع موضوع جديد`.
8. **جدول الأعمال** — 4 مراحل (دراسة/قيد المراجعة/معتمد/مؤجَّل) بقيم `—` + زر معطَّل `اعتماد جدول أعمال`.
9. **المحاضر والقرارات** — empty-state + زر معطَّل `إصدار قرار`.
10. **متابعة تنفيذ القرارات** — empty-state.
11. **الأرشيف** — empty-state.
12. **التقارير** — empty-state.
13. **إعدادات الجدولة والتنبيهات** — قائمة نقاط توضيحية + زر معطَّل `إرسال تنبيه`.
14. **نظرة معمارية (بطاقات تعريفية)** — 8 بطاقات: هدف البوابة، مجلس الكلية، مجالس الأقسام، دورة الموضوع، دورة الاجتماع، دورة القرار والمتابعة، الجدولة والتنبيهات المستقبلية، الأرشفة والتقارير.
15. **حاشية توضيحية** — تختم الصفحة بشرح متى تُفعَّل الوظائف التشغيلية.

كل زر عملياتي **`disabled`** مع سطر مجاور:
> «سيتاح بعد تفعيل قاعدة بيانات المجالس والصلاحيات.»

(زر التنبيهات له صياغة قريبة: «سيتاح بعد تفعيل خدمات التنبيهات المؤسسية.»)
