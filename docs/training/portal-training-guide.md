## 1. مقدمة عامة

### 1.1 هدف البوابة
البوابة الإلكترونية للكلية هي منصة موحّدة تجمع الخدمات الأكاديمية والإدارية والمالية في مكان واحد، وتُتيح:
- وصول الطلاب لسجلاتهم ودرجاتهم ووثائقهم.
- متابعة أعضاء هيئة التدريس للجداول والدرجات.
- إدارة شؤون الكلية من مكان واحد لإداريي الكلية.
- نشر معلومات الكلية الرسمية للجمهور.

### 1.2 الفئات المستفيدة
| الفئة | الاستخدام |
|---|---|
| الطلاب | عرض السجل، الدرجات، الرسوم، الطلبات، الوثائق |
| أعضاء هيئة التدريس | جداولهم، إدخال الدرجات، متابعة الطلاب |
| الموظفون الإداريون | تشغيل الخدمات اليومية حسب الدور |
| إدارة الكلية | المؤشرات، التقارير، اتخاذ القرار |
| الزوار | معلومات الكلية، الأقسام، الأخبار |

### 1.3 طريقة الدخول
- الموقع العام: الصفحة الرئيسية مفتوحة للجميع.
- بوابة الطالب: `/portal-login` ثم `/student`.
- بوابة عضو هيئة التدريس: `/portal-login` ثم `/faculty-portal`.
- بوابة الموظف: `/portal-login` ثم `/staff`.
- لوحة الإدارة: `/admin/login` ثم `/admin`.

### 1.4 أنواع المستخدمين
- **طالب** — حساب مرتبط بسجل أكاديمي.
- **عضو هيئة تدريس** — حساب مرتبط بملف أكاديمي.
- **موظف** — حساب مرتبط بملف وظيفي.
- **إداري / مدير نظام** — صلاحية الدخول للوحة الإدارة.

## 2. بوابة الطالب

### 2.1 تسجيل الدخول
1. افتح الرابط `/portal-login`.
2. أدخل البريد أو الرقم الأكاديمي.
3. أدخل كلمة المرور.
4. اضغط "دخول".
5. عند نسيان كلمة المرور: استخدم رابط `/forgot-password`.

### 2.2 لوحة الطالب
الصفحة الرئيسية `/student` تعرض:
- بطاقة ترحيب باسم الطالب.
- ملخص المستوى والقسم والمعدّل.
- روابط سريعة للدرجات، الجدول، الوثائق.
- آخر الإشعارات والإعلانات.

### 2.3 الدرجات
- الوصول من `/student` → "الدرجات" أو `/mobile/student/grades`.
- تعرض الدرجات حسب الفصل الدراسي.
- تشمل: الاسم، الكود، الدرجة، التقدير، النقاط.

### 2.4 السجل الأكاديمي
- صفحة `/student/progress`.
- يعرض كل المقررات المنجزة، الجارية، المتبقية.
- يحسب المعدّل التراكمي والساعات المعتمدة.

### 2.5 الرسوم والمدفوعات
- ضمن لوحة الطالب → قسم "المالية".
- يعرض الرسوم المستحقة، المدفوعة، المتأخرة.
- إيصالات الدفع متاحة للتنزيل.

### 2.6 الطلبات
- ضمن لوحة الطالب → قسم "الطلبات".
- إنشاء طلب جديد: اختر نوع الطلب → عبّئ البيانات → أرسل.
- متابعة حالة الطلب (قيد المراجعة / مقبول / مرفوض).

### 2.7 الوثائق الرسمية
- عرض الوثائق المُصدَرة من الكلية.
- إمكانية التحقق العام من وثيقة عبر `/verify-document`.
- تنزيل/طباعة الوثائق.

### 2.8 تطبيق الجوال / PWA
- الواجهة المخصصة للجوال على `/mobile/student`.
- تشمل: الصفحة الرئيسية، السجل، الدرجات، الجدول، الوثائق، الرسوم، الطلبات.
- تعمل دون اتصال جزئياً (Service Worker مُفعَّل).

### 2.9 تثبيت التطبيق على الهاتف
**iPhone (Safari):**
1. افتح البوابة في Safari.
2. اضغط أيقونة المشاركة.
3. اختر "إضافة إلى الشاشة الرئيسية".

**Android (Chrome):**
1. افتح البوابة في Chrome.
2. اضغط القائمة (⋮).
3. اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

## 3. لوحة الإدارة

### 3.1 الدخول للوحة الإدارة
1. افتح `/admin/login`.
2. أدخل بريد المسؤول وكلمة المرور.
3. يجب أن يكون لحسابك دور `admin` أو `system_admin`.

### 3.2 لوحة المؤشرات
- صفحة `/admin` تعرض المؤشرات الرئيسية.
- `/admin/executive-dashboard` للوحة التنفيذية الكاملة.
- يشمل: أعداد الطلاب، الأعضاء، الموظفين، الطلبات، حالة النظام.

### 3.3 إدارة الطلاب
- `/admin/students` — قائمة الطلاب مع الفرز والبحث والفلترة.
- إنشاء/تعديل/تعطيل سجل طالب.
- `/admin/student-progress` متابعة التقدم الأكاديمي.
- `/admin/at-risk-students` الطلاب المعرّضون للخطر الأكاديمي.

### 3.4 إدارة أعضاء هيئة التدريس
- `/admin/faculty-management` لإدارة الملفات الأكاديمية.
- `/admin/faculty-accounts` لإدارة الحسابات وربطها.

### 3.5 إدارة الموظفين
- `/admin/staff-management` لإنشاء وتعديل ملفات الموظفين.
- ربط الموظف بقسم وجهة العمل.

### 3.6 إدارة الأقسام والبرامج والمستويات
- `/admin/departments` — الأقسام الأكاديمية.
- `/admin/programs` — البرامج (مثل IT, CS, AI, IS).
- `/admin/academic-core` — المستويات والسنوات الأكاديمية.

### 3.7 إدارة المقررات والخطط الدراسية
- المقررات: ضمن `/admin/academic-core`.
- `/admin/study-plans` — الخطط الدراسية، ربط المقررات بالمستوى والفصل والمتطلبات السابقة.

### 3.8 إدارة الجداول
- `/admin/schedules` — الجداول الدراسية.
- `/admin/course-offerings` — مقررات الفصل الجاري.
- `/admin/enrollments` — تسجيلات الطلاب في المقررات.

### 3.9 إدارة الطلبات
- `/admin/student-requests` — مراجعة طلبات الطلاب.
- `/admin/request-types` — أنواع الطلبات المتاحة.

### 3.10 إدارة الوثائق
- `/admin/documents` — إصدار الوثائق الرسمية والتحقق منها.
- `/admin/transcripts` — كشوف الدرجات.

### 3.11 إدارة المالية
- `/admin/finance` — الرسوم، المدفوعات، التقارير المالية.

### 3.12 الإدارة العامة
- `/admin/communications` — الإعلانات والإشعارات.
- `/admin/news` — الأخبار.
- `/admin/events` — الفعاليات.
- `/admin/operations` — العمليات اليومية.
- `/admin/audit-log` — سجل التدقيق.
- `/admin/system-readiness` — جاهزية النظام.

## 4. الاستيراد الجماعي

### 4.1 فكرة الاستيراد
يتيح النظام إدخال كميات كبيرة من البيانات دفعة واحدة عبر ملفات Excel، مع تحقق صارم قبل الإدخال الفعلي.

### 4.2 تحميل القوالب الرسمية
1. افتح `/admin/imports`.
2. اختر نوع الاستيراد المطلوب.
3. اضغط "تحميل القالب".
4. سيُنزَّل ملف Excel فيه: ورقة بيانات + ورقة تعليمات.

### 4.3 تعبئة ملفات Excel
- لا تُغيّر أسماء الأعمدة (الصف الأول).
- التزم بصيغة الحقول الإلزامية كما في ورقة "Instructions".
- احفظ الملف بصيغة `.xlsx`.

### 4.4 Dry Run (التشغيل التجريبي)
1. ارفع الملف.
2. اختر وضع **Dry Run** (دون تنفيذ).
3. يعرض النظام تقريراً بالأخطاء والتحذيرات.

### 4.5 مراجعة الأخطاء
- الخطأ يحدد: رقم الصف + اسم العمود + سبب الخطأ.
- صحّح الملف الأصلي وأعد رفعه.
- استمر حتى يخلو التقرير من الأخطاء.

### 4.6 تنفيذ الاستيراد
1. بعد نجاح Dry Run، أوقف وضع التجربة.
2. فعّل خيار "تحديث القائم" عند الحاجة.
3. اضغط "تنفيذ".

### 4.7 قراءة تقرير الاستيراد
- عدد السجلات المُدرَجة.
- عدد المُحدَّثة.
- عدد المُتجاهَلة مع الأسباب.
- إمكانية تنزيل تقرير الأخطاء.

### 4.8 القوالب المتاحة
| القالب | الغرض |
|---|---|
| `departments` | الأقسام |
| `programs` | البرامج |
| `levels` | المستويات |
| `students` | الطلاب |
| `faculty` | أعضاء هيئة التدريس |
| `faculty_accounts` | حسابات أعضاء هيئة التدريس |
| `courses` | المقررات |
| `study_plans` | الخطط الدراسية |
| `staff` | الموظفون |

> ملاحظة: `credit_hours` للمقررات تُحسب تلقائياً: نظري + ⌈عملي ÷ 2⌉.
> الفصول المعتمدة: **الفصل الأول** و **الفصل الثاني** فقط (لا يوجد فصل صيفي).

## 5. إدارة الحسابات والصلاحيات

### 5.1 إنشاء حساب عضو هيئة تدريس
1. افتح `/admin/faculty-accounts`.
2. اضغط "إنشاء حساب".
3. أدخل البريد، الاسم، اختر الملف الأكاديمي.
4. أرسل بيانات الدخول للعضو.

### 5.2 ربط حساب موجود
- في `/admin/faculty-accounts` اختر "ربط حساب موجود".
- ابحث عن المستخدم، اربطه بالملف الأكاديمي.

### 5.3 استيراد حسابات أعضاء هيئة التدريس
- استخدم قالب `faculty_accounts` في `/admin/imports`.
- يولّد النظام الحسابات ويربطها بالملفات تلقائياً.

### 5.4 تصدير حالة الحسابات
- من `/admin/faculty-accounts` → "تصدير".
- يُصدَّر تقرير بحالة كل عضو (مرتبط / غير مرتبط / موقوف).

### 5.5 إدارة الأدوار
- صفحة `/admin/roles` لإدارة كتالوج الأدوار.
- إضافة دور جديد، تعديل، تفعيل/تعطيل.

### 5.6 إسناد الأدوار
- صفحة `/admin/user-roles`.
- ابحث عن المستخدم → اختر الدور → "إسناد".
- إذا كان للدور ربط تشغيلي (`app_role_mapping`)، يُضاف الدور التشغيلي تلقائياً.
- عند إزالة الدور، يُزال الدور التشغيلي فقط إن لم يكن مرتبطاً بدور آخر.

### 5.7 الفرق بين المسمى الوظيفي والدور النظامي
| البند | المسمى الوظيفي | الدور النظامي |
|---|---|---|
| المكان | في ملف الموظف | في `user_roles` |
| الغرض | وصف الوظيفة الإدارية | منح صلاحيات تشغيلية |
| التأثير | لا يمنح صلاحيات | يفتح صفحات وعمليات |
| أمثلة | "أمين القسم" | `admin`, `registrar`, `dean` |

## 6. التطبيق الجوال

### 6.1 الفرق بين PWA و APK
| البند | PWA | APK |
|---|---|---|
| التثبيت | من المتصفح | ملف Android مستقل |
| التحديث | فوري بدون تدخل | يحتاج إعادة تثبيت |
| الوصول | iOS و Android | Android فقط |
| الاستخدام الموصى به | الإطلاق الأول | لاحقاً عند الحاجة |

### 6.2 طريقة تثبيت PWA
راجع البند **2.9** أعلاه.

### 6.3 خطوات تجربة تطبيق الطالب
1. افتح `/mobile/student-login` على الجوال.
2. سجّل الدخول بحساب طالب اختباري.
3. تنقل بين الصفحات.
4. جرّب وضع عدم الاتصال (Airplane Mode) للتأكد من PWA.

### 6.4 الصفحات المتاحة في التطبيق
- الرئيسية
- السجل الأكاديمي
- الدرجات
- الجدول
- الوثائق
- الرسوم
- الطلبات

### 6.5 القيود الحالية
- بعض شاشات الإدارة غير مُهيّأة للجوال.
- المدفوعات الإلكترونية رهن التفعيل.
- الإشعارات الفورية (Push) قد تتطلب إعداداً إضافياً.

## 7. إجراءات التشغيل الأولي

### 7.1 إنشاء السنة الأكاديمية 2026-2027
1. `/admin/academic-core` → "السنوات الأكاديمية" → "إضافة".
2. السنة: 2026-2027، حدد الفصلين (الأول والثاني).

### 7.2 إدخال البيانات الأساسية
- الأقسام → البرامج → المستويات → المقررات → الخطط.
- يُفضَّل استخدام الاستيراد الجماعي.

### 7.3 استيراد الطلاب
- استخدم قالب `students` بعد التأكد من اكتمال الأقسام والبرامج.

### 7.4 إنشاء الحسابات
- حسابات أعضاء هيئة التدريس عبر `faculty_accounts`.
- حسابات الموظفين الإداريين عبر `/admin/users`.
- تخصيص الأدوار عبر `/admin/user-roles`.

### 7.5 التشغيل التجريبي
- تنفيذ سيناريوهات كاملة بحسابات اختبار.
- مراجعة الأخطاء وتسجيلها.

### 7.6 مراقبة الأداء
- `/admin/system-readiness` لحالة الجاهزية.
- `/admin/audit-log` لمراقبة العمليات.
- `/admin/operations` للعمليات اليومية.

## 8. المشاكل الشائعة وحلولها

| المشكلة | الحل |
|---|---|
| فشل تسجيل الدخول | تأكد من البريد وكلمة المرور؛ استخدم "نسيت كلمة المرور" |
| الطالب لا تظهر بياناته | تأكد من ربط `user_id` بملف الطالب في `student_profiles` |
| خطأ في الاستيراد | راجع تقرير Dry Run؛ صحّح الصفوف المُشار إليها |
| القسم غير موجود | أضف القسم أولاً عبر `/admin/departments` أو استورد الأقسام قبل الطلاب |
| البريد مستخدم مسبقاً | استخدم بريداً مختلفاً أو فعّل "تحديث القائم" |
| الحساب غير مربوط | افتح `/admin/faculty-accounts` → "ربط حساب موجود" |
| الوثيقة لا تفتح | تحقق من الصلاحيات؛ استخدم `/verify-document` بالرقم المرجعي |
| مشاكل العرض على الجوال | استخدم `/mobile/student` بدلاً من الواجهة العادية؛ حدّث المتصفح |

## 9. أفضل الممارسات

- ✅ استخدم **Dry Run** قبل أي استيراد فعلي.
- ✅ لا تستخدم حسابات حقيقية أثناء الاختبار.
- ✅ احتفظ بنسخة من ملفات الاستيراد الأصلية.
- ✅ لا تشارك كلمات المرور؛ لكل مستخدم حسابه الخاص.
- ✅ راجع الصلاحيات قبل منحها — مبدأ "أقل صلاحية ممكنة".
- ✅ تدرّج في التشغيل: قسم تجريبي → كامل الكلية.
- ✅ وثّق كل تغيير إداري كبير في `/admin/audit-log`.
