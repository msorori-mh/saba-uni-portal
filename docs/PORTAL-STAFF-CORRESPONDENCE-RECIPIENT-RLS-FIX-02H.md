# PORTAL_STAFF_CORRESPONDENCE_RECIPIENT_RLS_FIX_02H

تصحيح محدود لسياسة قراءة التعاميم. كانت سياسة 02A تقارن `correspondence_id` بمعرّف صف المستلم نفسه، لذلك كان الموظف يرى إيصال التعميم دون محتواه.

تعيد 02H إنشاء سياسة القراءة فقط بحيث يقارن صف المستلم مع `staff_correspondence.id` الخارجي، مع بقاء الشروط التالية كما هي:

- يجب أن يكون التعميم منشوراً.
- الموظف يرى فقط ما أرسل إليه حسب `auth.uid()`.
- الموارد البشرية ترى نطاقها المصرح.
- الأدمن يحتفظ بنطاقه الحالي.

التحقق الإنتاجي المطلوب: الموظف التجريبي يرى 3 تعاميم و3 إيصالات، بينما مستخدم مصادق غير مستلم لا يرى هذه التعاميم.
