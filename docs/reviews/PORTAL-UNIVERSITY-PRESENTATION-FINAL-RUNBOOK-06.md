# دليل العرض النهائي لمجلس الجامعة — 06

## قبل بدء العرض

1. افتح نافذة خاصة جديدة لضمان عدم بقاء جلسة مستخدم سابق.
2. استخدم حسابات العرض المعزولة المعتمدة، ولا تستخدم حسابات حقيقية.
3. ابدأ بد. رمزي، ثم سجّل الخروج قبل الانتقال إلى أحمد.

## مسار د. رمزي حميد

1. افتح `/portal-login` واختر «دخول بوابة أعضاء هيئة التدريس».
2. سجّل الدخول بحساب د. رمزي التجريبي.
3. في `/faculty-portal` ثبّت أمام الحضور:
   - د. رمزي حميد.
   - أستاذ مساعد.
   - رئيس قسم نظم المعلومات.
   - القسم: قسم نظم المعلومات.
4. افتح «المجالس الأكاديمية».
5. ثبّت أن المجلس الحالي هو «مجلس قسم نظم المعلومات» وأن الدور «رئيس المجلس».
6. يمكن الانتقال بعد ذلك إلى جدول التدريس، تنفيذ المحاضرات، المواد التعليمية،
   مشاريع التخرج، والتقارير بحسب سيناريو العرض.

## مسار أحمد سالم المخلافي

1. سجّل خروج د. رمزي بالكامل.
2. من `/portal-login` اختر «دخول بوابة الطالب».
3. سجّل الدخول بحساب أحمد التجريبي.
4. افتح `/student/progress`.
5. ثبّت المؤشرات التالية قبل متابعة العرض:
   - 99 ساعة مكتسبة.
   - 35 مقررًا مجتازًا.
   - معدل تراكمي 3.01.
   - إنجاز 86.1% من إجمالي 115 ساعة.
6. افتح «تدقيق المقررات» لإظهار السجل التاريخي للمستويات السابقة.
7. يمكن الانتقال بعد ذلك إلى الجدول والمواد ومشروع التخرج.

## تحقق سريع عند أي إعادة تشغيل

- إذا ظهر تقدم أحمد `0` أو معدل `0.00`، أوقف العرض ولا تستخدم الصفحة حتى إعادة
  فحص استعلام النتائج المعتمدة.
- إذا ظهر لد. رمزي قسم غير «نظم المعلومات»، أوقف العرض ولا تعرض التقارير أو
  المجالس حتى إعادة توحيد سياق الحساب.
- لا تنفذ تعديلات إدارية أو تغييرات بيانات أثناء العرض.
