3. STOP / HALT CONDITIONS (BLOCKER DEFINITIONS)
-----------------------------------------------
The runner plan will immediately HALT and alert operator ONLY under these conditions:
  1. DEPLOYED_SHA != SOURCE_SHA (stale build deployed).
  2. RLS Security Violation (unauthenticated or wrong role query succeeds in fetching restricted data).
  3. Admin Academic Bypass (admin role succeeds in casting council vote or altering grades).
  4. Data Integrity Corruption (chair uniqueness violated or broken multi-council role mappings).
  5. Cancelled Document Download Leak (cancelled certificate permits Signed URL download).
  6. Finance Leak (finance/payment elements displayed while adminFinance = false).
