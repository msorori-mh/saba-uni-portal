documents (including finance-options absence). Routes below are the only
authoritative report hubs.

2. PART 1: FIVE REPORT CENTERS
------------------------------

CANONICAL HUBS (do not use legacy /reports or /reports/strategic):
  Student:     /student/reports
  Faculty:     /faculty-portal/reports
  Department:  /admin/department-reports
  Executive:   /admin/executive-reports
  Admin:       /admin/reports

UX HIERARCHY (every hub using ReportsOperationalWorkspace):
  Level 1 data-reports-level="attention"  → يحتاج انتباهك الآن
  Level 2 data-reports-level="kpis"       → المؤشرات الرئيسية
  Level 3 data-reports-level="catalog"    → جميع التقارير

VIEWPORTS (manual browser):
  Desktop ≥1280, Tablet 768, Mobile 360 — RTL, no clipped headings, catalog cards wrap.

TEST H1.1: STUDENT SELF HUB
  Action: Login as student → /student/reports → refresh.
  Assertion: Three-level workspace; KPIs use ScopedMetric (never fake 0 for missing);
             catalog self-only; no other-student PII; logout clears RQ cache + favorites.

TEST H1.2: FACULTY SELF HUB
  Action: Login as faculty → /faculty-portal/reports.
  Assertion: Assigned sections/materials scope only; hierarchy intact; RTL.

TEST H1.3: DEPARTMENT HEAD SCOPING
  Action: Department head → /admin/department-reports.
  Assertion: Bound department only. Foreign department drill-down DENY / empty fail-closed.

TEST H1.4: DEAN FAIL-CLOSED DEPARTMENT DETAIL
  Action: Dean → /admin/department-reports without admin role.
  Assertion: No arbitrary department picker; redirected/fail-closed to college/executive hubs.
             Dean college overview via /admin/executive-reports?view=dean succeeds.

TEST H1.5: EXECUTIVE / STRATEGIC BINDING GATES
  Action: Staff without presidency/VP binding → /admin/executive-reports strategic/VP views.
  Assertion: BLOCKED / binding-required — not openable as LIVE. Dean/registrar alone ≠ presidency.

TEST H1.6: ADMIN CATALOG + SECTION TABS
  Action: Admin → /admin/reports (catalog tab + students/requests/…).
  Assertion: Catalog uses three-level workspace; BLOCKED/NOT_ACTIVATED not openable;
             exports from current filtered rows only; no email/phone/national_id in projections.

TEST H1.7: CATALOG CONTRACT SPOT-CHECK
  Action: Inspect visible ReportEntry cards.
  Assertion: Each shows real source, honest status, role scope, org scope, route or
             «قيد التجهيز», filters, output types. No fabricated KPI tiles.

TEST H1.8: DIRECT BACKEND DENIAL
  Action: Call department/executive summary server fns as wrong role / wrong dept.
  Assertion: Auth denial (not coerced to DATA_INCOMPLETE / empty success with zeros).

TEST H1.9: ACCESSIBILITY / ROUTE REFRESH
  Action: Keyboard tab through attention→KPIs→catalog; hard refresh each hub URL.
  Assertion: aria-labelledby headings present; severity text (حرج/تنبيه/معلومة);
             state survives refresh via server re-fetch (no stale cross-user cache).
