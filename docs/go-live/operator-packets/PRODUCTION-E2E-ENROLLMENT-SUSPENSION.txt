STEP C1.3: REFERENCE OPTIONS LOOKUP

  Assertion: Returns active upcoming term options.

STEP C1.4: DRAFT / AUTOSAVE LIFECYCLE

  Action: Query `student_requests` where `id = REQ-SUSP-2026-001`.
